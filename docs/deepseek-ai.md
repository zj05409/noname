# 出牌建议、DeepSeek 与牌局记录

本功能基于[官方无名杀](https://github.com/libnoname/noname) v1.11.6，沿用 GPL-3.0。原版 AI 与 DeepSeek 共用一个游戏入口；首次打开时，DeepSeek 总开关默认关闭，建议来源默认选择「原版 AI」。设置保存在当前浏览器中。

## 使用

1. 按原版流程进入本机身份局。保持 DeepSeek 关闭，即可先体验游戏自带 AI。
2. 在自己的出牌或选择提示出现时，点击「给我建议」。默认使用本机原版 AI，不消耗 Token；DeepSeek 总开关关闭时也能使用。
3. 点击「助手设置」，可分别设置「电脑使用 DeepSeek」与「给我 DeepSeek 建议」。两项都受「启用 DeepSeek」总开关控制。
4. 要让模型给自己建议，开启总开关和玩家建议，并在「建议来源」选择 DeepSeek。也可使用「电脑原版，我用 DeepSeek 建议」预设。

建议在独立大窗口中显示全文，可滚动、复制或重新获取。两种来源都只给建议，不替玩家点击出牌。原版建议调用游戏自身的评分，支持简单实体牌、普通目标、是否发动及选项；复杂转换技能、特殊按钮或自定义流程会提示手动判断。DeepSeek 玩家建议按点击请求，不在后台持续分析。

## 模型的信息范围

模型只接收当前决策者合法知道的局面和已经发生的信息：自己的手牌、已知的其他玩家牌、公开体力、装备、判定、武将与技能，以及公开行动历史。未知手牌、其他人的未公开真实身份、牌堆顺序和完整本地录像不会发送。

电脑自己的真实身份属于它合法知道的信息。对其他未亮身份，模型只能从公开行为进行带置信度的推断；猜测不会被替换成真实隐藏身份。每台电脑分别保留策略计划、压缩记忆与身份猜测，牌桌上的实时提示只展示电脑的公开选择，私有计划和解释留在本地复盘轨迹中。

玩家的 DeepSeek 建议发送当前已知局面与公开历史，候选列表为空。获取建议不会枚举假设出牌、试探未来局面或执行引擎操作。

## 策略与执行

真实电脑回合开始时，Pro 进行一次回合规划；具体出牌、响应和玩家建议使用 Flash。回合外响应直接请求 Flash，不重复进行 Pro 规划。请求关闭长思考模式，后端不自动重试。

策略包含资源保留、留桃救援、群体锦囊、无懈与反无懈，以及身份局的阵营推断。无懈请求提供正在抵消的锦囊、原始目标和反无懈链状态；救援请求提供濒死对象和所需桃数量。这些信息仍遵守决策者的已知信息范围。

电脑接入出牌、响应、选牌、目标、弃牌、是否发动与控制项七类选择。有限搜索覆盖最多四张实体牌、三个目标、自动全目标牌及最多 64 个普通候选。模型只能选择引擎验证为合法的候选；复杂技能、特殊按钮或自定义选择继续使用原版 AI。超时、请求失败、无效答案或局面变化时，也会继续采用原版 AI。

默认每次电脑请求的服务端时限为 15 秒、客户端等待上限为 22 秒；手动玩家建议分别为 45 秒与 50 秒。回合规划和动作选择是独立请求，因此一次电脑回合可能包含多次等待。界面会显示分析状态及失败原因；关闭相关开关会取消尚在等待的请求。

本功能用于本机离线对局，联机模式跳过模型接入。DeepSeek 需要联网并产生 API 用量费用。尚未进行大量胜率对比，不能据此保证真人水平或固定胜率。

## 本地记录与回放

新牌局自动记录原生录像与 AI 轨迹，关闭 DeepSeek 时也可记录原版 AI 的选择。点击「牌局记录」，可以查看整场过程、筛选 AI 决策、展开当时输入与返回结果，核对实际执行、失败、过期答案和回退情况。

用量按 API 返回的实际输入、输出与总 Token 统计，分别展示全部、电脑及玩家建议。服务没有回报用量的请求标为「未知」，不会按零消耗计算；已知合计不包含这些未知请求。原版本机建议不发生模型调用。

记录保存在当前浏览器的本地数据库中，默认保留最近 30 场。可导出包含原生录像和 AI 轨迹的 JSON，再导入恢复。清除浏览器数据会删除本地记录，需长期保留的牌局请先导出。

「回放录像」使用无名杀原生回放流程，会离开当前牌局并重新进入录像；录像中的暂停、速度等操作沿用原版。回放时可查看对应 AI 轨迹，不重新调用模型。完整录像可能包含复盘所需的隐藏信息，但它只留在本地，不进入模型请求。

## 安装与运行

使用官方要求的 Node.js 和 pnpm 安装依赖，完整检出音频、图片素材后运行：

```sh
pnpm install
pnpm build:deepseek
pnpm start:deepseek --config /安全位置/deepseek.json --port 8081
```

稀疏 worktree 可通过 `NONAME_ASSETS_DIR` 指向另一份官方 `apps/core` 素材目录；该目录必须包含 `image` 和 `audio`。

外部配置文件必须放在 Git 仓库和游戏服务目录之外，权限建议为 `0600`：

```json
{
  "baseUrl": "https://api.deepseek.com/v1",
  "apiKey": "在本地填写，不要提交",
  "model": "deepseek-flash",
  "planModel": "deepseek-v4-pro",
  "timeoutMs": 15000,
  "adviceTimeoutMs": 45000
}
```

也支持 `DEEPSEEK_API_KEY`、`DEEPSEEK_BASE_URL`、`DEEPSEEK_MODEL`、`DEEPSEEK_PLAN_MODEL`、`DEEPSEEK_TIMEOUT_MS`、`DEEPSEEK_ADVICE_TIMEOUT_MS` 环境变量。未指定 `planModel` 时，规划沿用普通模型。

API Key 只由本机 Node 服务读取，不放入前端、浏览器存储、模型局面或请求日志。服务仅绑定 `127.0.0.1`，校验来源与候选 ID，并限制请求大小、并发和等待时间。游戏文件接口只允许读取；网页导入扩展等需要写文件的功能暂不支持，正常游戏配置仍保存在浏览器中。
