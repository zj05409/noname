# DeepSeek 出牌助手

本功能基于官方无名杀 v1.11.6，沿用 GPL-3.0。一个游戏入口，右侧「启用 DeepSeek」全局开关首次默认关闭。关闭时所有电脑采用原版 AI，也不会请求玩家建议接口。开关选择保存在当前浏览器中。

## 使用

1. 按原版流程进入身份局；建议先试玩默认关闭的原版 AI。
2. 勾选「启用 DeepSeek」，电脑开始使用模型规划与决策。
3. 在自己的出牌或选择提示出现时点击「给我建议」。按钮只显示建议，不替你执行动作。
4. 「全场手牌（全知）」开启时，模型可读取所有玩家手牌；取消后只读取当前决策者手牌、已知牌与公开局面。

电脑自己的真实身份属于它合法拥有的信息。其他未亮身份一律以「未知身份」发送，由模型结合行为推断；不会把真实隐藏身份当作推理结果提供。电脑私有计划与解释也不会显示给人类玩家。

## 策略与执行

每个离线电脑回合开始时发送全场血量、手牌、装备、判定区、已公开武将与技能、近期公开行动及历史行为统计。每台电脑分别保留策略计划、压缩记忆和带置信度的身份猜测，之后的选择继续发送最新局面。

策略提示覆盖留桃与救援、群体锦囊的阵营收益与防御资源、无懈和反无懈的关键目标、内奸平衡双方与准备爆发。无懈请求包含正在抵消的锦囊、原始作用目标、反无懈链状态；救援请求包含濒死对象和所需桃数量。模型只能选择引擎当前验证为合法的候选。

接入出牌、响应、选牌、目标、弃牌、是否发动与控制项七类选择。有限搜索覆盖最多四张牌、三个目标、自动全目标牌及最多 64 个普通候选；复杂转换技能、特殊按钮或引擎自定义选择仍使用原版 AI。模型选择原版 AI 候选、超时、格式错误或局面变化时，也会继续采用原版 AI。

本功能目前用于本机离线对局；联机模式跳过模型接入。策略代码已经加入身份推断与跨回合记忆，但没有完成大量胜率对比实验，不能据此保证达到真人水平或固定胜率。

## 安装与运行

使用官方要求的 Node.js 和 pnpm 安装依赖，完整检出音频、图片素材后运行：

```sh
pnpm install
pnpm build:deepseek
pnpm start:deepseek --config /安全位置/deepseek.json --port 8081
```

稀疏 worktree 可通过 `NONAME_ASSETS_DIR` 指向另一个官方 `apps/core` 素材目录；该目录必须包含 `image` 和 `audio`。

外部配置文件格式如下，必须放在 Git 仓库和游戏服务目录之外；权限建议为 `0600`：

```json
{
  "baseUrl": "https://api.deepseek.com/v1",
  "apiKey": "在本地填写，不要提交",
  "model": "deepseek-flash",
  "planModel": "deepseek-v4-pro",
  "timeoutMs": 15000
}
```

也支持 `DEEPSEEK_API_KEY`、`DEEPSEEK_BASE_URL`、`DEEPSEEK_MODEL`、`DEEPSEEK_PLAN_MODEL`、`DEEPSEEK_TIMEOUT_MS` 环境变量。未指定 `planModel` 时，规划沿用普通模型。当前安装使用 Pro 规划回合、Flash 处理具体动作和玩家建议；请求关闭长思考模式，以控制等待时间。

API Key 只由本机 Node 服务读取，不放入前端、浏览器存储、模型局面或请求日志。服务仅绑定 `127.0.0.1`，校验来源与候选 ID，并限制请求大小、并发和等待时间。游戏文件接口只允许读取；网页导入扩展等需要写文件的功能暂不支持，正常游戏配置仍保存在浏览器中。

## 验证

```sh
pnpm test:deepseek
pnpm lint
```

测试覆盖合法性、强制选择、过期答案、默认关闭、玩家建议不执行动作、两种手牌视野、身份记忆、真实回合规划、无懈与救援上下文、超时和文件访问隔离。另须使用真实浏览器验证原版 AI 对局及开启后的模型请求与动作结算。
